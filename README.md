## How the projects are consolidated

A GitHub Actions workflow automatically imports the six original public repositories into the numbered directories. This keeps the final internship submission self-contained while preserving each project's original structure.

Each project has its own `README.md` and `requirements.txt`. Follow the project-specific instructions when running an individual project.
